# @graphique/geom-histogram

For visualizing histograms in [Graphique](https://graphique.dev).

With larger data sets, pre-compute bins and pass the binned data directly to [`@graphique/geom-col`](https://graphique.dev/docs/geoms/col).

## Install

```sh npm2yarn copy
npm install @graphique/geom-histogram # @graphique/graphique is a peer dependency
```
