# @graphique/geom-col

For visualizing data as vertical bars/columns in [Graphique](https://graphique.dev). For horizontal bars, try [`@graphique/geom-bar`](https://graphique.dev/docs/geoms/bar).

## Install

```sh npm2yarn copy
npm install @graphique/geom-col # @graphique/graphique is a peer dependency
```
